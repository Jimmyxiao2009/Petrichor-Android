# 1.0.1：按确认稿修正原生 UI

确认稿位于 `design/android/`，对应 Superdesign 保存的35份已确认页面。此轮没有改动稿件和设计系统，全部指纹保持一致；原生实现对照这些文件修改。

## 修改

- 首页恢复三列图标快捷卡片、两列方形封面、播放量角标和分区间距。
- 搜索恢复56dp圆角搜索框、36dp矩形筛选标签、选中状态及独立节目卡片；移除多余的输入框原生边框。
- 播客首页加入双列封面与最近更新列表；详情页统一180dp封面、居中信息和操作区。
- 我的页面区分访客与登录状态，保留本地/下载/历史；已登录列表末尾保留订阅播客、歌手和专辑入口。
- 登录恢复图标标记、居中标题、下划线页签和浮动标签表单；验证码按钮嵌入验证码输入区，保留安全存储和发送成功后的倒计时。
- 设置恢复外观分组卡片和图标行；主题、音质和定时弹层继续执行实际操作。切换动态取色不再重建页面或丢失导航。
- 播放器恢复封面、曲目信息、细进度轨道、竖形拖动柄、大播放键及底部工具区；歌词、队列和睡眠定时沿用相同组件。
- 歌曲长按菜单加入封面、图标和拖动条；新建歌单使用居中对话框，收藏到歌单使用底部弹层。
- 多选时收起歌单封面和介绍，显示选择数量及底部操作；返回键先退出多选。检查框宽度和回收行对齐已修正。
- 保持播放栏贴边固定；Android 12+ 动态配色及浅色/深色均使用统一资源。

- Release 构建0错误；3条 NETSDK1215 提示来自保留 UWP 兼容性的共享核心目标。
- 81项业务检查再次通过，日志为 `artifacts/ui-refinement/core-tests.log`。
- Android 15 x86_64 模拟器验证覆盖安装、冷启动、搜索分类、节目所属播客、长按、播放/暂停、播放器/歌词/队列、公开歌单多选、手机登录页面、二维码、设置及主题切换。
- 比对页：`artifacts/ui-refinement/index.html`；APK指纹与范围：同目录 `report.json`。截图来自本轮1.0.1构建，最后版本复核安装、选择行对齐和分类标签；曲目、封面和数量为实时数据。
