# Petrichor 1.0.4

本轮把布局间距与多数固定尺寸收紧至原来的 78%，文字缩至约 85% 并保留最小字号。歌单网格改成三列；底部播放栏继续贴边。没有通过修改系统密度或缩放整棵视图来实现。

## 播放、评论与导航

1. 播放详情移除“正在播放 · 专辑”说明行。封面／歌词、进度和控制固定在屏内；点击封面切换歌词，点击歌词可跳转时间。
2. 封面上滑进入独立功能区，拖动带阻尼并吸附到整页。返回按钮与下拉手柄分开，避免手势吞掉点击。系统返回键优先退出功能区。
3. 不循环、列表循环、单曲循环使用对应图标／高亮与点击动画；随机播放显示开关状态。状态没变时不重复设置按钮资源。
4. 保留原生 SeekBar 的拖动、键盘与无障碍语义，改为波浪已播轨道；滑块两侧分别留出间隔。点按轨道与非拖动调节也会提交播放跳转；界面写入进度时不反向触发跳转。跳转完成后再次刷新，覆盖暂停状态没有计时刷新的情况。
5. 评论框使用原生编辑缓冲区，默认一行，按实际行数增至最多四行。Android 15 边到边窗口按实际遮挡避让键盘。评论行复用控件，减少滚动时重新创建视图。
6. 全部 Ui.Push／Pop 统一淡入位移转场，评论、播放与歌词使用竖向进入／退出，其他栈页面使用横向位移。根标签页也有转场，保留导航互斥以防重复返回。关闭系统动画时跳过相关动画。

## 下载、音质与颜色

- 空列表使用同一个可滚动 Header 中的空态，修复内容较长的空下载页无法滚动。新空态接口支持显式清除，游客“我的”页不再重复显示默认空态。
- 目录选择使用 Android ACTION_OPEN_DOCUMENT_TREE 与持久读写授权。新下载保留应用内离线副本，同时复制到指定文件夹；已有文件不会自动迁移。导出格式按实际 FLAC／MP3 等格式设置扩展名。下载进度更新现有行，不再每次清空列表。
- 新增无损与 Hi-Res 选项，使用 EAPI song/enhance/player/url/v1 的 level 与 encodeType=flac。保留服务端实际格式、码率、试听信息和降级信息，不能把 MP3 标成无损。
- 切歌或切音质时释放旧播放器；取消的旧加载请求不能把错误写回新歌曲。
- 状态栏与窗口背景使用同一 Surface，图标明暗跟随应用主题；保留 Android 12+ 壁纸动态取色与旧系统默认配色。
- 日推／排行榜和私人 FM 的多余宣传句已移除。

## 验证与证据

- Core：101 项通过，包括真实解密请求的 FLAC level／签名、实际格式解析和有损回退识别。
- 安卓交互：11 项通过，覆盖三态循环、歌词时控制可见、封面上滑、按钮与手柄返回、评论输入高度与键盘、小屏下载滚动和控制可见。
- 原生输入：13 项通过，覆盖快速输入、邮箱切换区号、密码遮罩／显隐、退出清空、浮动标签和短信入口。均为测试字符，没有提交真实密码或发送短信。
- 公开页面：发现、搜索、节目、播客、歌单、榜单、歌手、专辑、歌词、评论、登录、下载、设置与游客账号页截图检查。长内容进行了滚动；短内容自然结束，不要求强行滚动。
- 自制 24 位 / 44.1 kHz / 双声道 FLAC 已通过最终 Release 的正式文件选择流程导入并在 Android MediaPlayer 中成功播放；SAF 导出前后 SHA256 相同。游客真实无损请求返回 403，会员无损尚待真实账号条件验证。
- 最终 APK 是 Release 1.0.4 / versionCode 5，非 DEBUGGABLE；从设备拉取安装 APK 与交付文件逐字节哈希一致。
