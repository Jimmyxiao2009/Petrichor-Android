# 1.1.0 · Material Design 3 界面、导航与动效

版本：1.1.0 / versionCode 12。播放、登录、歌单、评论、下载等后台逻辑未改，Core 与播放服务源码未动。

## 基础

- **色彩**：主题色板改为在 Activity 主题上叠加覆盖层。开启动态取色时使用 Material 的动态覆盖层，否则使用 `values/styles.xml` 中的静态覆盖层。静态色板由品牌色 #B91C42 经 Material Color Utilities 生成，包含全部 MD3 角色（含 surface container 各级）。MAUI 资源从主题属性读回，原生控件（开关、底部面板、对话框、提示条、导航栏）与 MAUI 界面颜色一致。深色模式启动画面使用深色背景。
- **尺寸与字体**：去掉原来全局 ×0.78 尺寸、×0.85 字号的缩放，改用 MD3 字号层级（`UI/Md.cs`），标题与标签使用 Medium 字重。按钮为 40dp 容器、48dp 触控区；图标按钮为 40dp 圆形容器、48dp 触控区。页面左右边距统一 16dp，圆角按 MD3 形状等级取值。
- **按压反馈**：卡片、列表项、页签、芯片、图标按钮统一使用原生波纹（`UI/Pressable.cs`）。原来用点击手势的卡片没有任何按压反馈。

## 导航

- 底部导航栏显示文字标签，选中项使用实心图标与 SecondaryContainer 指示器。
- 详情页保留底部导航栏，每个标签页有独立的返回栈。再次点击当前标签会回到该页根部，已在根部时滚动到顶部。播放器、登录、评论、私人 FM 仍为全屏页面。
- 迷你播放条改为全局唯一，插在页面区域与导航栏之间（`UI/ShellChrome.cs`、`UI/MiniPlayer.cs`），切换页面时保持不动。输入法弹出时导航栏与迷你播放条会暂时让开。

## 组件

顶部栏 64dp，内容滚动后背景渐变为 SurfaceContainer，加载时底部显示线性进度条。另外调整了：

- 搜索栏改为 56dp 胶囊形；
- 页签指示条滑动到选中项，宽度跟随文字；
- 筛选芯片选中时显示勾号；
- 输入框标签浮动并带动画；
- 列表项为 72dp，带 56dp 封面，正在播放的项目使用 SecondaryContainer 底色；
- 设置与播放功能改为分组圆角列表；
- 底部面板和对话框使用 Material 原生实现，当前选项带勾号；
- 提示信息从页面顶部横幅改为底部提示条（Snackbar），需要登录时附带"登录"操作；
- 加载骨架会缓慢呼吸。

## 动效

- 页面进入与返回改为 MD3 共享轴转场，由 Shell 的 Fragment 事务执行，新旧页面同时移动并交叉淡入淡出。原来返回时上一页没有入场动画，会突然出现。Shell 在转场期间会把容器涂成黑色，现已改为页面底色。
- 全屏页面（播放器、评论等）从下方升起，下层页面保持显示；关闭时下沉淡出。封面在迷你播放条与播放器之间飞行，圆角同步过渡。
- 切换底部标签使用 fade through（淡入并从 92% 放大）。
- 列表、推荐和排行榜在内容替换加载骨架时轻微上浮进场；搜索结果每次搜索都会进场。
- 播放键暂停时为圆形、播放时变为圆角方形；播放/暂停、喜欢、循环图标切换带缩放。喜欢、随机、循环按下时有弹跳反馈，替代原来的旋转晃动。
- 歌词当前行渐亮并放大，上一行淡出，原来是瞬间切换。拖动进度时预览气泡淡入。

## 问题修复

- "获取验证码"按钮在发送请求后会被重新启用，倒计时期间也能再次点按。
- 多数详情页右上角的"更多"按钮实际打开的是设置页。现在只在有菜单的页面显示。
- 加载骨架颜色在切换深浅色后不更新。
